Configuração do Banco na Nuvem (Supabase)

Conecte gratuitamente para produção multi-usuário

Para que os cadastros enviados por qualquer pessoa do Brasil apareçam na sua fila de moderação, crie um projeto gratuito no Supabase.com, cole o código SQL abaixo no menu SQL Editor e preencha as constantes SUPABASE_URL e SUPABASE_ANON_KEY no topo do script deste arquivo: 

create table diretorio_itens (
  id bigint generated by default as identity primary key,
  tipo text not null,
  nome text not null,
  categoria text not null,
  plataforma text,
  uf text,
  cidade text,
  endereco text,
  contato text not null,
  descricao text not null,
  status text default 'pendente',
  motivo_denuncia text,
  created_at timestamp with time zone default timezone('utc'::text, now())
);

alter table diretorio_itens enable row level security;

-- Qualquer visitante vê apenas itens aprovados (ou moderadores veem tudo)
create policy "Leitura publica e moderacao" on diretorio_itens
  for select using (status = 'aprovado' or auth.role() = 'authenticated');

-- Visitantes podem enviar novos cadastros sempre como pendente
create policy "Envio publico pendente" on diretorio_itens
  for insert with check (status = 'pendente');

-- Colaboradores autenticados podem aprovar, editar ou excluir
create policy "Moderadores gerenciam tudo" on diretorio_itens
  for all using (auth.role() = 'authenticated');

Para adicionar novos colaboradores no futuro sem revelar sua identidade, basta criar um login para eles na aba Authentication > Users do Supabase.
